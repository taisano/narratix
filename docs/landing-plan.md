# 紹介トップ（A/B）・入り口のリデザイン・フィードバック：実装計画

元の指示書：`docs/landing-ab-guide.md`（v2）。デザインの見本：`docs/design/landing-mock/`。見本は別の道具（Tailwind・vinext）で作った静的なモックなので、そのまま取り込まない。レイアウトと雰囲気の参考にして、このリポジトリの CSS Modules・部品・i18n で作り直す。

## 決めたこと（2026-09-26）

| 項目 | 決定 |
|---|---|
| URL | `/` を紹介トップにする。エディターは `/editor` へ移す。今までの `/?chart=…` などは `/editor?…` へ自動で転送する |
| A/B の計測 | 自前の簡単な計測を足す。初回に半々で割り当て、同じブラウザでは固定。`?variant=a/b` は確認用で、割り当ても計測も変えない。記録先は Supabase の `ab_events` だけ。相談文・データ・メールは送らない |
| フィードバック | Supabase に保存し、同時にメールで通知する（Resend）。キーが未設定の間も保存はされる |

## 指示書・モックと、今のコードの突き合わせ

- **`/` がエディター**：`src/app/page.tsx` が Builder。内部リンクは `/?chart=`、`/?library=`、`/?libraryEdit=`、`/?new=1`、`/?plan=1`、`href="/"`。これらはマイページ・履歴・Library・StartFlow・SetPassword・AppShell にある。
  - エディターを `/editor` へ移し、内部リンクをすべて書き換える。
  - `/` に上のクエリが付いてきた時は `/editor` へ転送する（ブックマーク互換）。
- **ヘッダー**：アプリの画面は今の AppShell のまま（ナビ：新しく作る・エディタ・Library・マイページ、言語、アカウント）。
  - 紹介トップは専用の軽いヘッダーにする：使い方・見本を見る・ベータ版について・Beta バッジ・「無料で試す」（ログイン済みなら「作成を始める」）・言語。
  - アカウントの詳細は AccountMenu にまとめる。
- **目的の選択**：今は複数選択で、「評価」は準備中。
  - モックは単一選択で5つだけだが、指示書に従い、複数選択のまま「2つ以上選べます」と明示する。
  - 評価は「準備中」の無効な見た目で残す。
- **相談文の上限**：モックは 500 字、今は 800 字（`CONSULT_MAX_CHARS`）。800 のまま、文字数の表示だけ足す。
- **ヒーロー・見本・PreBuilt の絵**：モックは CSS で描いた図形。本物のエンジンで描いた SVG（見本データ）に置き換える。
  - 絵ごとに「ダミーデータ」と明記する。
  - 架空の実績・ロゴ・推薦コメントは作らない。
- **見本（3件）**：DB に頼らず、見本データをエンジンで描く（成長の軌跡と速さ・全体と内訳の変化・基準と比べた差）。「ほかの見本を見る」は `/library` へ。
- **ベータ・安心材料**：今の登録画面の「利用条件とプライバシー（要点）」と同じ中身を使う。
  - 相談文だけを AI に送り、データは送らない。
  - 履歴は本人だけが見られ、消せる。
  - 出力後も PowerPoint で編集できる。
  - 詳細はモーダルで開く。
- **ステップ表示**：紹介トップには出さない。`/start` では控えめにし、スマホでは「ステップ 1/4：入口」の1行にする。
- **A/B/C の文字ラベル**：`/start` の入り口カードから外す。
- **英語**：指示書のコピーは日本語だけ。英語は下書きを `src/features/landing/copy.ts` に入れた（要確認）。
- **文字の大きさ**：紹介トップと `/start` の本文は 16px 以上。エディターは今のまま。

## ルート

| URL | 中身 |
|---|---|
| `/` | 紹介トップ（A/B）。`?chart` `?library` `?libraryEdit` `?new` `?plan` 付きで来たら `/editor?…` へ転送 |
| `/editor` | 今のエディター（BetaGate 付き）。中身は変えない |
| `/start` | 入り口のリデザイン（相談＞目的＞チャート）。`#chart-library` でチャート一覧を開いた状態 |
| `/library` `/charts` `/join` `/account/password` | 変えない（リンク先だけ `/editor` に直す） |
| `/api/feedback` | フィードバックの受付（保存＋メール通知） |

## 作るもの

### 1. 紹介トップ（`src/features/landing/`）

- 構成：`LandingPage.tsx` を部品に分け、`copy.ts` の案の文言だけを差し替える。案ごとにページを複製しない。
- ヒーロー：コピー＋主要 CTA（→ `/start`）＋「見本を見る」（→ `#examples`）＋補足1行。
  - 右側に相談 UI と完成スライド（エンジンの SVG）を重ねる。
- 01 課題：「まず、チャートを作る」と「まず、伝え方を相談する」の比較。
- 02 使い方：3ステップ。
- 03 見本：3件。
- 04 PreBuilt：紺の背景。Mekko を大きく、Waterfall・Slope・Bubble・Chart+Table を小さく並べる。「PreBuilt チャートを見る」は `/start#chart-library` へ。
- ベータ：3つの安心材料と「詳しく」（モーダル）。
- 最終 CTA、フッター（フィードバックへのリンクも）。
- 幅：375・390・768・1440 で確認する。キーボードのフォーカスが見えること、見出しの順番が正しいことも確かめる。

### 2. A/B（`src/lib/ab/`）— 下準備済み

- `variant.ts`：案の決め方と訪問者の番号。テスト済み。
- 追加予定の `track.ts`：`ab_events` へ記録する。失敗しても画面は止めない。`forced`（URL 指定）の時は記録しない。
- 記録するイベントと場所：

| イベント | 場所 |
|---|---|
| `landing_view` | トップ |
| `landing_primary_cta_click` | トップ |
| `landing_examples_click` | トップ |
| `landing_prebuilt_click` | トップ |
| `start_view` | `/start` |
| `start_consultation_selected` | 相談を送った時 |
| `start_purpose_selected` | 目的で始めた時（識別子だけ） |
| `start_chart_library_opened` | チャート一覧を開いた時 |
| `angle_selection_completed` | ② → ③ |
| `library_opened` | Library |

- トップ以外の画面では、覚えている案を付けて記録する（URL には付けない）。

### 3. `/start` のリデザイン（`StartFlow.tsx` の Entry だけ）

- 見出し「何を伝えたいですか？」と補足を置く。
- 相談カード：いちばん大きく、「おすすめ」付き。
  - 文字数表示、例文、空なら押せない。
  - AI・履歴・データ送信の説明は要約と「詳しく見る」にまとめる。
  - 未登録なら登録へ（今の動きのまま）。
- 目的：「目的が決まっている方はこちら」。問いを大きく出し、推移・比較などは小さなラベルにする。
  - 複数選択のまま、評価は準備中。
- チャート：いちばん下の閉じたアコーディオン（`#chart-library`）。直接来た時は開いて、そこまでスクロールする。
- 相談・目的・チャートの処理（`onConsult` など）と ② 以降は変えない。

### 4. フィードバック

- 開ける場所：
  - アプリのヘッダーの「フィードバック」（全画面）
  - 紹介トップのフッターとベータ欄
  - AccountMenu
- フォーム：種類（不具合・使いにくい・要望・その他）、内容（必須・4000 字まで）、返信先メール（任意。ログイン中は初期値）。
  - 今の画面の URL は自動で付ける（パスだけ）。
- `/api/feedback`：
  - 入力を確かめ、スパム除けの隠し欄を置き、同じ IP から10分に5回までにする。
  - 送った人として（未ログインなら匿名で）`beta_feedback` に保存する。
  - `RESEND_API_KEY` と `FEEDBACK_TO_EMAIL` があれば、Resend の API でメールを送り、`notified` を立てる。
- 読む：届いたメールで読む。管理者用の一覧画面は後で必要なら作る（SQL でも読める）。
