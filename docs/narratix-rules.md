# NarratiX の計算・判定ルール（Code.gs から抽出）

出典：`reference/narratix/Code.gs`（NarratiX MVP V36 CODEX／アプリ版 V38_6_FreeBeta）。行番号は同ファイルのもの。
Web 版で**挙動を合わせる**ものと、**Web 版で変える**ものを分けて書く。変える場合は `docs/decisions.md` に理由を残す。

## 1. データの読み方（MATRIX_TIME_SERIES / MEKKO 共通）

- 表は「1列目＝横軸の項目（X）× 2列目以降＝系列」。見出しが `total`（大文字小文字を問わない）の列は系列から除く（`getDataItems_` 5256）。
- 項目名の正規化 `norm_`（897）：数値として読める名前は**整数に丸めた文字列**にする（例：`2025.0` → `2025`）。`/` を含むもの（日付）はそのまま。
- 空欄のセルは `null`（0 ではない）。数値にできないセルも描画時は `null`（`buildTrendLineContextFromHelper_` 2353）。
- **軸の入れ替え（axis_swap）**：`NORMAL`＝行が横軸、`SWAPPED`＝列が横軸。表を転置してから同じ描画に渡す（`_buildHelperFlipped_` 5424）。
- **表示する項目・系列の絞り込み**：選んだ行・列だけを残す。並び順は入力順のまま。

## 2. Trend（推移）

### 縦軸の範囲（`computeTrendLineBounds_` 2376）— 折れ線・縦棒・横棒で共通
- 表示中の全系列の数値から最小・最大を取る。**最小が正なら 0 から始める**（`min = 0`）。
- 最小＝最大なら最大に +1。
- 上下に **範囲の 8% の余白**を足す（`min − 8%`、`max + 8%`）。※最小が 0 のときも下に余白が付く（見本どおりに合わせるかは要判断 → 下記「Web 版で変える」）。
- 目盛は **5本**（範囲を4等分）。

### 値ラベル（`formatTrendLineValueLabel_` 2402）
- 整数ならそのまま、そうでなければ**小数1桁**（末尾 `.0` は消す）。桁区切りなし。

### 折れ線（`drawTrendLineOnSlide_` 2426）
- 空欄は**線を途切れさせる**（前後をつながない）。
- マーカー：`line_markers` が ON のとき全点。強調中の系列は OFF でもマーカーを付ける。
- 強調（highlight）：強調系列は濃紺 `#0B2D4D`・太さ 3、他は `#D6DDE5`・太さ 1.7。**強調系列を最後に描く**（最前面）。凡例も同じ色分け。
- 値ラベル（data_labels＝ALL）：点の上に表示。同じ位置・同じ値のラベルは 10px ずつ上にずらす。強調系列のラベルは太字・濃紺。
- 項目が1つだけなら中央に置く。

### 縦棒・横棒（`drawTrendBarColumnOnSlide_` 2579）
- 系列を横に並べた**集合棒**。1項目の幅の 72%（上限あり）に系列数分の棒を並べる。
- 空欄の棒は描かない。
- 強調・値ラベルの扱いは折れ線と同じ（棒の上／右に表示）。
- ※負の値の扱いが不完全（高さを `|値−最小|` で出している）。→ Web 版で直す。

### CAGR（`buildCalc` 5170、`calcCAGRFromData_` 6544）
- 横軸の項目が「年」（1900〜2100 の整数が2つ以上）なら、**最小の年→最大の年**で系列ごとの CAGR を出す。
- 年数＝最大年−最小年。始点が 0 以下、または空欄なら `N/A`。
- 表示は `%` で小数1桁（例：`12.3%`）。
- 行が年でなく、列が年なら、列方向で同じ計算（行ごとの CAGR）。どちらも年でなければ「CAGR は計算できません」。
- クイックインサイトに「CAGR（2021→2025）」として系列ごとに並べる。

### 色
- 通常の系列の色：`#1F3B5C #2E6C9E #0F766E #C9822B #7A6F9B #7A8450 #8A817C #9AA8B5 #A06E6E #6B8C7A`、11系列目からはグレー。
- 積み上げ・100% 積み上げ・Mekko 用：`#1F3B5C #3E74A4 #258E86 #5D9CC6 #8CC2D8 #E2A066 #D7B35A #C5D2DD`。
- 強調：対象 `#0B2D4D`、それ以外 `#D0D5DA` 系（棒）／`#D6DDE5`（線）。

## 3. Comparison（比較）

**重要：比べる「項目」は列（系列）、「対象」は行（横軸の項目、多くは年）。** 軸を入れ替えると逆になる。

### 比較の対象（compare_target）— 横棒ランキング・縦棒比較（`buildComparisonData_` 1220）
- 行（横軸の項目）を1つ選ぶ。**既定は最後の行**（例：最新年）。見つからなければ最後の行。
- その行の各列の値で並べる。数値でない・空欄の列は**除外**。
- 並び順：`DESC`（既定・降順）／`ASC`（昇順）／`INPUT_ORDER`（入力順）。
- 強調：対象の棒を濃紺、ほかをグレー 1色（`#D0D5DA`）。

### 基準と比較先（base_target / compare_target2）— 集合縦棒・差分バー（`buildVarianceData_` 1256）
- どちらも行（横軸の項目）。**既定は基準＝最初の行、比較先＝最後の行**。
- 同じ行が選ばれたら既定に戻す。行が2つ未満なら描けない。
- **差＝比較先 − 基準（実数）**。どちらかが空欄・数値でない列は除外。
- 並び順：差の降順（既定）／昇順。同じ差なら入力順。
- 差のラベル（`formatVarianceSignedValue_` 1662）：`+12` / `-3.5` / `0`。小数1桁まで、末尾 `.0` は消す。
- 集合縦棒の差ラベルは矢印付き：`↑ +12`、`↓ -3`。既定で表示（`SHOW_DIFFERENCE_LABELS=ON`）。
- 差分バーの色：プラス `#2E7D32`、マイナス `#C62828`、0 `#9AA0A6`、0 の線 `#6B7280`。
- クイックインサイト（`formatComparisonDeltaText_` 6576）：「+12 (+8.5%)」＝差と、基準に対する % 変化（基準が 0 なら差のみ）。

## 5. Contribution（参考：後のマイルストーン用）

`parseDriverBridgeRows_` 周辺（1399〜1490）：
- 終点が空欄なら「始点＋要因の合計」で自動計算して警告。
- 合計が合わない時：`ADD_OTHER`（既定）＝差を「その他 / 調整」として足す、`AUTO_FIX`＝終点を合計に合わせる。誤差の許容は 0.000001。
- 値0の要因は `show_zero` が ON の時だけ表示（調整項目は常に表示）。
- 変化率＝(終点−始点)/始点（始点が 0 なら null）。

## 6. Web 版で変える点（案）

- **縦軸の下限**：最小が 0 以上なら下限は 0 ちょうど（余白を付けない）。棒グラフは 0 始まりが原則のため。
- **負の値の棒**：0 の線を基準に上下（左右）に描く。
- **数値の表記**：NarratiX は桁区切りなし・小数1桁。Web 版はスライドの言語に合わせた桁区切りを付け、`number_format`（自動・K・M・%）を効かせる。
- **並び順の選択肢**：比較の並び順に「入力順」を足す（NarratiX にはあるがレジストリになかった）。
- 年の判定（1900〜2100）と CAGR の計算は NarratiX に合わせる。
