# ②「最も伝えたいこと」の言い方の見直し案（実装前・意見募集）

作成：2026-10-09（Claude）。実装はまだしていない。Codex／ユーザーの意見を受けてから決める。

## 何をしようとしているか

1枚の「伝える内容と見せ方」画面は ① 答える問い → ② 最も伝えたいこと → ③ データの見せ方 の3段。
③ は「折れ線・縦棒・スロープ」などの形式だけにしたので、② には **形式の言葉（軌跡・推移を見る等）や、別の目的と同じ言葉（「構成の変化」が2か所）を残さず、「このスライドで読み手に何を読み取ってほしいか」だけ**を書く。

- 変えるのは **画面に出す言葉（ラベル）だけ**。内部ID（`trajectory` など）、推薦ロジック、保存形式は変えない。
- ラベルは `src/features/start/coach.ts` の `EMPHASIS_LABEL`（ja/en）。変更は1か所。
- 書き方の原則：①「〜を見る／比べる」など読み手の行動で終える、②チャート名・形式名を入れない、③同じ言葉を別の目的で使わない、④1つ14字前後まで（Boxに収まる）。

## 決めてほしいこと（推移の4つ）

指示書の例では、推移の ② を「値の動きを追う／期間ごとの大きさ／2時点の順位・差／伸びの速さ」にしたい。
現状の4つ（変化の軌跡・伸びの速さ・成長の牽引役・構成の変化）との関係は次のとおり。

- **案A（推奨）**：既存の4つの言葉だけを直す（上の表）。新しい伝えたいことは足さない。「期間ごとの大きさ」は ③ の縦棒、「2時点の順位・差」は ③ のスロープで選べる（今の構成のまま）。
- **案B**：指示書のとおり、推移の4つを「値の動きを追う／期間ごとの大きさ／2時点の順位・差／伸びの速さ」に入れ替える。この場合、成長の牽引役・構成の変化は推移から外れ、**「要因」「構成」の目的からしか選べなくなる**。さらに、新しい2つの伝えたいことに推薦の候補（`MAP`）と採点を足す必要があり、変更が大きい。
