

## 料金プランの見直し — 2026-10-11
- 基本（無料）は続ける。登録（メール）は必要。AI 相談は累計5回、スライド作成は月15枚、出力は月30回（透かしあり）、Story なし。
- Plus は AI 相談 月100回、作成 月100枚、出力 月200回、透かしなし。Pro は作成・出力が無制限で、Story・コーチにおまかせ・新機能の優先招待。AI 相談は月300回。
- 料金ページは比較表。「AI 相談」は公正利用の話ではなく「相談文から AI が切り口を提案する機能」と明記。「無制限」の注意書き（1日の上限）を添える。
- 作成・出力は暦の月（UTC）で数え、毎月1日に戻る。同じスライドの編集・再保存は数えない。

## Stripe 連携（段階C）— 2026-10-19
- 前払いで確定。1か月・3か月ごと・12か月ごとの定期支払いにし、3か月以上は月額換算の割引価格をまとめて請求する（自動更新・期間末で解約）。Stripe の価格はプラン×通貨×期間の18個。ユーロはドルと同じ数字。
- SDK は入れず、REST（fetch）と署名検証だけで実装した。依存を増やさず、挙動を単体テストで確かめやすくするため。
- プランの切り替えは Webhook だけが行う（画面の「成功」には頼らない）。RPC `apply_stripe_subscription` は service_role だけが実行でき、同じ通知の二重処理・古い通知・別の購読の終了通知を防ぐ。`past_due` は猶予として有料のまま。
- 課金のスイッチは2つ（画面 `NEXT_PUBLIC_BILLING_ENABLED`、サーバー `STRIPE_SECRET_KEY`）。両方そろうまで従来の「関心の記録」のまま。本番鍵なのに本番の Price ID が無ければ止める。
- 商品カテゴリー（税区分）と Managed Payments は、税・本番化の判断なので、専門家の確認後に決める（今は変更しない）。
- プランの変更（Plus⇄Pro）はカスタマーポータルで許す。契約中の人には、別プランのボタンを「プランを変更する」（ポータルへ）にする。日割りの設定は専門家の確認後に決める。
- Managed Payments は、Checkout 作成時に `managed_payments[enabled]=false` を明示して使わない（アカウント側の既定で有効でも切る）。使う場合は環境変数 `STRIPE_MANAGED_PAYMENTS=1`＋商品の税コード設定が必要。販売者・税込表示・特商法の表記に関わるため、専門家の確認後に決める。
- 料金表の選択は「通貨」と「月払い／3か月以上」の2つだけにする（要素を減らすため）。「3か月以上」は3か月ごとの前払い。12か月ごとの価格は画面に出さない（Stripe・コードには残す）。Stripe へ移動中の表示は、押したボタンだけに出す。
